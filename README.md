# 🍱 MealCircle

MealCircle is a full-stack web application built using **Spring Boot** and **React.js** that connects **mess owners** and **customers/students** on one platform.

Users can discover nearby mess services, explore meal plans, subscribe to messes, and manage their daily food needs efficiently.

---

# 🚀 Features

## 👤 User Features
- User Authentication (Signup/Login)
- Browse nearby mess services
- View mess details and meal plans
- Subscribe to mess services
- Search and filter messes
- Responsive UI

## 🏪 Mess Owner Features
- Register and manage mess profile
- Add/update meal plans
- Upload mess images
- Manage subscribers
- Track customer subscriptions

## 📍 Location Features
- Google Maps API integration
- Nearby mess recommendation
- Live location storage during registration

## 🔐 Security Features
- Spring Security Authentication
- JWT-based Authorization
- Role-Based Access Control (User / Mess Owner)
